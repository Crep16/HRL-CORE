## HRL-21: conservación del seguimiento

Rama `fix/HRL-21-preserve-repair-storage`.

Antes, un JSON ilegible cargaba un seguimiento vacío y el siguiente
guardado podía reemplazar el original. Un JSON con listas o campos
incorrectos también podía romper la pantalla o los cálculos.

Ahora se validan etapas, notas, eventos, garantías, refacciones, pagos y
visibilidad. Los registros parciales válidos conservan sus valores y
reciben valores iniciales para campos ausentes. Los registros ilegibles
bloquean todas las escrituras de esa sesión y muestran un aviso mediante
el mensaje existente. No se intenta reparar ni eliminar el original.
Un error de escritura conserva el borrador y permite reintentar. La
validación también se ejecuta antes de guardar.

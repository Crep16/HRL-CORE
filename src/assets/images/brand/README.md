# Logo HRL

Reconstrucción vectorial de `LOGO@2x.png`, proporcionado como referencia del proyecto. Se conservan el monograma enlazado HRL, el corte curvo y los colores rojo/olivo; las curvas se regularizaron manualmente y se eliminó el margen blanco excesivo.

Todos los SVG tienen fondo transparente. El monograma y el nombre están convertidos a trazados: no contienen imágenes incrustadas ni requieren fuentes instaladas. La leyenda se recompuso con Calibri Bold y se convirtió a contornos; no es un calco exacto del texto rasterizado. El original PNG permanece intacto.

| Archivo | Uso |
| --- | --- |
| `hrl-original.svg` | Logo principal, rojo `#A30D2D` y olivo `#758B2E`. Integrado como imagen predeterminada en la aplicación. |
| `hrl-azul.svg` | Alternativa en azul petróleo `#17384A` con contorno azul `#1B72AD`. |
| `hrl-negro.svg` | Una tinta oscura `#12222D`, para impresión y fotocopias. |
| `hrl-blanco.svg` | Blanco, para fondos oscuros; el archivo no incluye un fondo. |
| `hrl-rojo.svg` | Rojo de una tinta `#A30D2D`. |
| `hrl-contorno.svg` | Contorno del monograma y nombre sólido, útil para sellos y grabado previa prueba del proveedor. |

Cada versión tiene una alternativa `hrl-symbol-*.svg` sin el nombre completo. Usa estas versiones en tamaños pequeños. Como referencia de legibilidad digital, utiliza el logo completo desde unos 180 px de ancho y el monograma desde unos 64 px; verifica el tamaño real del soporte.

Mantén las proporciones y una zona libre alrededor equivalente, como mínimo, al grosor de un trazo. Para fondos claros utiliza original, azul u oscuro; para fondos oscuros utiliza blanco. No añadas sombras ni deformes el monograma.

La galería está en `docs/brand/index.html`. El encabezado de la aplicación y las notas usan el monograma original en sus espacios pequeños; el nombre del negocio ya se muestra como texto en la nota. Empresa muestra el logo completo en su panel de configuración. Las preferencias de logos personalizados ya guardadas conservan la imagen elegida por el usuario; el SVG reemplaza únicamente el logo incluido por defecto.
